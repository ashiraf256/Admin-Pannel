How to prepare GitHub (quick)

  1. Create a repo named leoxtream (or your preferred name). Public is fine.
  2. Upload an initial empty movies.json file (use the template provided in the repo).
  3. Create a GitHub Personal Access Token (Settings → Developer settings → Personal access tokens → Generate new token) with repo scope. Copy it temporarily to paste into the admin's GitHub Token field when pushing.
  4. Enable GitHub Pages if you want to host the admin from the same repo (Settings → Pages → Deploy from branch → main).
